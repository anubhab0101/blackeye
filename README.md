## Overview

BlackEye is a tool designed for educational purposes to demonstrate phishing techniques. It allows users to create phishing pages for various platforms to understand how such attacks can be conducted and to develop strategies for defense against them.

## Features

* Generates phishing pages for multiple platforms
* Simple and user-friendly interface
* Intended for cybersecurity awareness and training

## Installation

To set up BlackEye on your system, follow these steps:

```bash
git clone https://github.com/anubhab0101/blackeye.git
unzip blackeye-master.zip
cd blackeye-master
sudo ./blackeye.sh
```



*Note: Ensure you have the necessary permissions and dependencies installed on your system.*

## Usage

After installation, run the `blackeye.sh` script to launch the tool. Follow the on-screen instructions to select and deploy phishing pages for educational demonstrations.
